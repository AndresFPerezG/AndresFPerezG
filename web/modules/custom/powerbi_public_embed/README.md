# Power BI Public Embed (Drupal custom module)

Módulo de ejemplo para embeber reportes de Power BI en un portal Drupal público con controles básicos de seguridad:

- endpoint público con allowlist por slug
- generación backend de token temporal
- rate limit por IP+slug
- modo demo (`mock_mode`) para pruebas locales
